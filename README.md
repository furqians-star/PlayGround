## 🕹️ NEON BREAKER

A complete browser arcade game in a single file (`index.html`) — no build step, no dependencies.

- **8 handcrafted levels** with 1–3 HP bricks and unbreakable steel bricks
- **Power-ups:** wide paddle, multiball, slow-mo, sticky paddle, extra life
- Combo scoring, particles, screen shake, synthesized sound effects (WebAudio)
- High score saved in `localStorage`; pause with **P**/Esc; mouse, touch, and keyboard controls

Just open `index.html` in any modern browser to play.
